# Word Poem Graph — Path Layout (Split Files)
Files:
- index.html
- style.css
- app.js
- words_test_30.json

How to run locally:
1) Open a terminal in this folder.
2) Start a local server, e.g.:
   python3 -m http.server 8000
3) Open http://localhost:8000 in your browser.
4) Click right-side options to extend the poem. Click any path word to collapse.
   Shortcuts: 1/2/3 choose options · M mute/unmute.
